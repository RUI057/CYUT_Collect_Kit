# 台灣手語資料收集包

[台灣手語辨識專案](https://github.com/RUI057/CYUT_Project)的資料收集工具。
**只負責收集資料**：用攝影機錄製手語動作，收完打包傳給組長，不需要訓練、也不需要 GPU。

## 開始（Windows）

1. 按右上角綠色的 **Code → Download ZIP**，解壓縮到任何位置
   （或用 GitHub Desktop／`git clone`）
2. 雙擊 **`開始.bat`**，第一次會自動設定環境（下載約 280 MB，3～10 分鐘，畫面一直跑字是正常的）
3. 在選單選「收集資料」，照畫面上的提示比手語

完整操作說明（按鍵、常見問題、攝影機權限）請看 **[使用說明.md](使用說明.md)**。
不知道某個詞怎麼比：打開 [手語演示網址.txt](手語演示網址.txt)，找到那個詞點影片看示範。

## 收完之後

在選單選「**打包資料**」，會產生 `手語資料_名字_日期.zip`，把它傳給組長即可。

## 需求

- Windows 10/11、攝影機
- Python 3.9～3.12（建議 3.11；**不要 3.13 以上**，mediapipe 還不支援）。沒有的話 `開始.bat` 會問你要不要自動安裝

## 注意

這個專案的程式是從主專案自動產生的（詞彙表與比法提示也是），請不要直接修改；
詞彙表更新時組長會重新發佈，到時請重新下載。
